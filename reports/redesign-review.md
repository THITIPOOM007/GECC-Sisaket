## ผลงานและระบบดีไซน์

ปรับหน้าแรกเป็นพื้นสีงาช้าง หัวข้อสีกรมท่า/เขียว ใช้ทองเป็นจุดเน้น พร้อมตราจังหวัดและ GECC จากเอกสารจริง การ์ดเปิดหลักสูตรมีมิติและเชื่อมไปกำหนดการประชุมจริง ใช้ Prompt สำหรับหัวข้อและ IBM Plex Sans Thai สำหรับข้อความ เนื้อหาหลักขนาด 15–17px บนมือถือ มี fallback Tahoma/sans-serif

สีหลัก: Ink `#142d3b`, Teal `#096b64`, Paper `#f7f8f4`, Gold `#e8c78b`; ข้อความรอง `#526775` ความกว้างเนื้อหาสูงสุด 1240px ระยะขอบมือถือ 16–20px การ์ดใช้ขอบบาง มุม 10–16px และเงาเฉพาะจุด ปุ่มหลักสูงอย่างน้อย 52px

โมชั่นประกอบด้วยการเปิดการ์ด การแสดงเนื้อหาเมื่อเลื่อน หน้าต่างรายละเอียด การตอบสนองเมื่อชี้/กด และแถบความคืบหน้าการอ่าน มีปุ่มหยุดโมชั่นและ CSS `prefers-reduced-motion` ภาพตกแต่งส่วนแรกหยุดเมื่อพ้นหน้าจอ ไม่มีวิดีโอเล่นอัตโนมัติ

## ประสิทธิภาพและความปลอดภัย

HTML/CSS/JS รวมก่อนบีบอัด 134,272 bytes ณ การตรวจ static ครั้งแรก ใช้ buildless static ไม่มี framework runtime ภาพรายชื่อใช้ WebP และ lazy loading เอกสาร PDF ขนาดใหญ่โหลดเมื่อเปิดลิงก์เท่านั้น ไม่มีการฝัง PDF ในหน้าแรก ตัวเลขนี้เป็นขนาดซอร์ส ไม่ใช่คะแนน Lighthouse หรือ Core Web Vitals ภาคสนาม

เก็บเฉพาะดัชนีเช็กลิสต์ใน localStorage ใช้ key/ลำดับเดิมครบ ไม่เก็บข้อมูลส่วนบุคคล ไม่มีการส่งคะแนนหรือสมัครแทนผู้เรียน ไม่พบคีย์ AI ในไฟล์ที่เผยแพร่ รายงาน AI ฉบับแยกยืนยัน **NO ACTIVE AI MODEL INTEGRATION DETECTED**

## ข้อจำกัดและสิ่งที่ยังไม่ได้ทดสอบ

1. ทดสอบเบราว์เซอร์ Chromium ผ่าน in-app browser; ยังไม่ได้ทดสอบ Safari/Firefox หรืออุปกรณ์จริง iOS/Android จึงไม่อ้างว่าผ่านทุกเบราว์เซอร์
2. ตรวจ accessibility เฉพาะโครงสร้าง label/keyboard/focus/reduced-motion และหน้าจอจริง ยังไม่มีการรับรอง WCAG หรือทดสอบ screen reader แบบครบชุด
3. รายชื่อพี่เลี้ยงแต่ละบุคคลอยู่ในภาพต้นฉบับ ยังไม่มีข้อความถอดรายชื่อทั้ง 23 คนสำหรับ screen reader
4. Drive/Canva เป็นปลายทางภายนอกซึ่งอาจต้องมีสิทธิ์หรือเปลี่ยนแปลงภายหลัง ได้เก็บลิงก์เดิมและเพิ่มไฟล์แนบหลักไว้บน Site; ไม่อ้างว่าได้ดาวน์โหลดทุกเอกสารภายนอก
5. ฟอนต์ Google ต้องใช้อินเทอร์เน็ต มีฟอนต์ระบบสำรอง; ไม่มี offline/PWA
6. ไม่มีบัญชีผู้เรียน แบบทดสอบ คะแนน ใบประกาศ ฐานข้อมูล Dashboard ผู้ดูแล หรือ AI ในระบบเดิม จึงไม่สร้างปุ่มจำลองหรืออ้างว่ามีฟังก์ชันเหล่านี้
7. ความพร้อมบันทึกเฉพาะอุปกรณ์/เบราว์เซอร์ ไม่ซิงก์ข้ามเครื่องและอาจหายเมื่อผู้ใช้ล้างข้อมูล
8. คงสิทธิ์การเข้าถึง Site แบบส่วนตัวสำหรับเจ้าของตามเดิม
