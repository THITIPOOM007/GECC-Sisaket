# GECC Sisaket Learning 2570

เว็บไซต์เรียนรู้และเตรียมความพร้อมมาตรฐานศูนย์ราชการสะดวก จังหวัดศรีสะเกษ ปี 2570

โทนสว่างน้ำเงิน ฟ้า ขาว ทอง ใช้ฟอนต์ไทยมีหัว Sarabun หน้าแรกกระชับ พร้อมทางเข้าเรียนรู้ ระบบประเมิน และคลังเอกสาร

## เปิดใช้งาน

ไม่ต้องติดตั้งแพ็กเกจหรือ build:

```sh
python -m http.server 4173 --directory dist
```

เปิด http://127.0.0.1:4173/ ตรวจโค้ดด้วย `node scripts/validate.cjs`

## ส่วนประกอบ

- `dist/index.html`: หน้าแรกและเนื้อหาหลักสูตร 8 กลยุทธ์ / 6 สัปดาห์ / เครือข่าย / คณะทำงาน / เอกสาร 21 รายการ
- `dist/navigation.js`: เปลี่ยนหมวดด้วย hash และคงลิงก์เดิม
- `dist/workspace.css`: ธีมและโครงหน้าพื้นที่เรียนรู้; `dist/light.css`: รูปแบบพื้นฐานของส่วนเดิม
- `dist/app.js`, `dist/updates.js`: การค้นหา แท็บ รายการความพร้อม และข้อมูลโครงการ
- `dist/assessment/`: ระบบประเมิน GEN1 ที่นำมาต่อจาก [kanokwipha-RX/GECC-websiteGEN1](https://github.com/kanokwipha-RX/GECC-websiteGEN1) โดยคง JavaScript เดิม ผู้พัฒนาเดิม Kanok_rx สำนักงานสาธารณสุขจังหวัดศรีสะเกษ
- `dist/assets/`: คู่มือ หลักเกณฑ์ กำหนดการ คำสั่ง และภาพต้นฉบับ
- `DESIGN.md`, `reports/workspace-review.md`: แนวทางออกแบบ แหล่งอ้างอิง ผลตรวจ และข้อจำกัด

## สถานะระบบประเมิน

GEN1 เป็น **ต้นแบบสาธิต** ตัวเลขที่ตั้งต้นเป็นข้อมูลจำลอง ข้อมูลและไฟล์แนบเก็บใน localStorage / IndexedDB ของเบราว์เซอร์เท่านั้น PIN ใช้สาธิตบทบาท ไม่ใช่การยืนยันตัวตนบนเซิร์ฟเวอร์ ยังไม่มีฐานข้อมูลกลางหรือการซิงก์ระหว่างผู้ใช้ ไม่ควรใช้จัดเก็บข้อมูลส่วนบุคคลจริงจนกว่าจะพัฒนาระบบหลังบ้าน

ระบบเดิมมีแบบประเมิน คะแนน การส่งกลับแก้ไข รายงาน PDF ส่งออก/นำเข้าข้อมูล และไฟล์แนบ ฟังก์ชันเหล่านี้ถูกเก็บไว้ ไม่ได้แทนด้วยหน้าจอจำลองใหม่ รายการเตรียมความพร้อมในส่วนเรียนรู้แยกจากผลประเมินและเก็บด้วย key `gecc-readiness-v1` ตามเดิม

ข้อมูลในเบราว์เซอร์ผูกกับโดเมนและอุปกรณ์ การเปิดคนละโฮสต์จะไม่ย้ายข้อมูลเดิมอัตโนมัติ การส่งออก PDF ของ GEN1 ใช้ CDN ของ html2canvas/jsPDF ตามต้นฉบับ ฟอนต์โหลดจาก Google Fonts เอกสาร Google Drive ขึ้นกับสิทธิ์ของเจ้าของไฟล์ ไม่มี AI API หรือ AI chatbot ทำงานอยู่

## แหล่งข้อมูลและออกแบบ

เอกสาร GECC 2570 และภาพที่ผู้ใช้ให้มา, Google Sites ของโครงการ, Canva โครงการ, Claude artifact ที่ผู้ใช้ระบุ และโค้ด GEN1 commit `c8301456b7851f0331f4ea2474954ff4000d9926`

ดึงโค้ดอ้างอิง Tabs (coss.com, 11639) ผ่าน 21st CLI แล้วประยุกต์ sliding indicator ให้เข้ากับแท็บเดิม ส่วน Cards Stack ที่ศึกษาระหว่างออกแบบครั้งแรกไม่ได้ใช้ในหน้าแรกฉบับปัจจุบัน ไม่ได้ติดตั้ง React/Motion เพิ่ม

ปรับปรุง 27 ตุลาคม 2569 ตรวจ 45 คู่หน้า/ขนาดหน้าจอ ไม่พบหน้าเว็บล้นแนวนอน ดูรายละเอียดและข้อจำกัดในรายงาน ไม่ใช่การรับรอง WCAG อย่างเป็นทางการ
